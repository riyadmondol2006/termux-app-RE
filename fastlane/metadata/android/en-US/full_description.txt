Termux RE is an unofficial fork of the Termux terminal emulator and Linux environment for Android. It is built under its own package name, com.termux.re, so it installs next to the official Termux app, and uses an updated build toolchain. It is not affiliated with or endorsed by the Termux project.

* A full terminal emulator with extra keys, multiple sessions and hardware keyboard support.
* Runs the Bash shell and the core command line utilities from its bootstrap packages.
* Works without root.

Termux packages have their install path compiled in. Termux RE builds for com.termux.re therefore need bootstrap packages built for that package name, and installing further packages with 'pkg' needs a package repository built for it. The packages from the official Termux repositories only work in an app with the package name com.termux. See the project README for how to build bootstraps and packages, or how to build the app with the package name com.termux.

Source code and issue tracker: https://github.com/riyadmondol2006/termux-app-RE
