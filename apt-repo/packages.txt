# The packages of the Termux RE package repository: the "Build packages" workflow builds them
# when it is started without a package list, and the repository always keeps them, with their
# runtime dependencies. Names are termux-packages package or subpackage names (a subpackage, like
# curl, is built through the package it comes from, like libcurl); other subpackages are only
# kept when they are listed. Packages whose current version is already in the repository are
# skipped, so running the workflow again only builds what changed in termux-packages.
#
# The repository is hosted on GitHub Pages, which allows 1 GB for everything, so the packages are
# tiered by architecture: nearly all phones are aarch64, which gets the most, older 32-bit phones
# (arm) get the command line tools, and x86_64/i686 (emulators, Chromebooks) the base set. Each
# section starts with the architectures it is for. Sizes are what a package adds to its tier,
# with its dependencies, measured with the official Termux repository.

[aarch64 arm i686 x86_64]
# Everything in the bootstrap, so `pkg upgrade` and `pkg reinstall` work for it, and the apt,
# termux-keyring and termux-tools packages that point at this repository.

gawk grep gzip inetutils less lsof nano net-tools patch procps psmisc sed tar termux-core
termux-exec termux-keyring termux-tools unzip util-linux
# Python (python-ensurepip-wheels for python -m venv), git, ssh, editors, shell, network,
# files and archives, manual pages, proot-distro for full Linux distributions.
python python-pip python-ensurepip-wheels make git openssh rsync vim zsh tmux htop
ncurses-utils curl wget openssl-tool zip file tree jq which mandoc proot proot-distro
# Small everyday tools, under 4 MB together.
micro fzf ripgrep fd ncdu termux-services sqlite bc nnn netcat-openbsd
