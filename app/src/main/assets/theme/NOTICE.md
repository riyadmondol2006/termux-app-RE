# Theme Studio assets

- Bundled color schemes (`BundledThemes.java`): original palettes authored for Termux RE, MIT licensed (same license as this project). No third-party scheme files are bundled.
- Bundled fonts: none are shipped as binary files. Theme Studio offers the system monospace typefaces and importing any user-supplied TTF (for example OFL-licensed fonts such as JetBrains Mono or Fira Code, obtained by the user). Imported fonts are copied to ~/.termux/font.ttf and are never redistributed by the app.
